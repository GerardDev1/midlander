# Midlander default keymap

**Source:** the default shortcut list in Fade In 4.1.1's built-in help (Help > Shortcut Keys). Gerard supplied it on 2026-11-26. Midlander uses the same defaults so Fade In users don't have to relearn anything. Every shortcut is rebindable in Preferences > Shortcut Keys.

On Windows/Linux, Midlander follows Fade In's Windows column (mostly Ctrl in place of Cmd, Alt in place of Option). Only the Mac column is listed here.

Status: ⬜ planned · ✅ implemented. All are ⬜ until the editor exists.

## Not carried over

- **Collaborate > Chat (Cmd+")**: realtime collaboration is out of scope for v1.
- **Fade In's hidden debug-logging shortcut**: Midlander will have its own.

## Notes on macOS conflicts

- **Cmd+Enter / Shift+Cmd+Enter** work as listed.
- **Option+Enter for full screen** differs from the usual macOS Ctrl+Cmd+F. Midlander binds both.
- **Shift+Cmd+?** opens the macOS Help menu search; Cmd+? opens Midlander help.
