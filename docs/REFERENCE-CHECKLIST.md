# Reference checklist for Gerard

These are the things I can't learn from Fade In's public documentation. Please capture them from your installed copy and add them to the repo (or attach them in chat).

**Important:** work on a *copy* of any script, never your originals. Nothing here changes Fade In itself.

## How to take screenshots on Monterey

- **Cmd+Shift+4, then Space, then click a window** → screenshot of one window (best for dialogs)
- **Cmd+Shift+4, drag** → screenshot of an area (best for open menus)
- **Cmd+Shift+3** → whole screen
- Screenshots land on your Desktop. Rename them with the numbers below, e.g. `A3-format-menu.png`.

To capture an **open menu**: click the menu so it's showing, then press Cmd+Shift+4 and drag over it.

## Where to put them

On GitHub: open the `midlander` repo → **Add file → Upload files** → drag them in → put them in a folder called `reference/` (type `reference/` before the file name in the upload page, or just upload and I'll move them) → **Commit changes**.

Or just attach them to our chat.

## E. Behaviour tests (just write down what happens)

In a new blank script:

- [ ] E1 For each element, what happens when you press **Enter** at the end of a line? (e.g. "Dialogue + Enter → Action")
- [ ] E2 For each element, what does **Tab** do on an **empty** line, and at the **end** of a line with text?
- [ ] E3 Type `int.` at the start of a line: what happens? Same for `ext.`, `i/e`.
- [ ] E4 Type a character name you've used before: how does autocomplete appear, and which key accepts it?
- [ ] E5 After a scene heading `INT. KITCHEN -`, what does autocomplete offer?
- [ ] E6 What happens with **Shift+Enter**, **Option+Enter**, **Cmd+Enter**?
- [ ] E7 Does Fade In open multiple scripts as tabs or as separate windows?
