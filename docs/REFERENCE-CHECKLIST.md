## How to take screenshots on Monterey

- **Cmd+Shift+4, then Space, then click a window** → one window (best for dialogs)
- **Cmd+Shift+4, then drag** → an area
- Screenshots land on your Desktop. Rename them with the codes below, e.g. `C1-main-window.png`.

Attach them in chat. **Don't upload scripts to the GitHub repo**: it's public, so anyone can see what's in it.
